# Red Lines

- Never read, inspect, summarize, hash, or evaluate the sealed test set in this arena.
- Never edit locked evaluator, launcher, budget, environment, manifest, program, or red-line files after launch. Candidate work is confined to `train.py`.
- Never hard-code gene symbols. Candidates configure only parent, panel/pool sizes, forest geometry, and benefit threshold.
- Never derive an outer fold's panels or pools from that fold's assessment rows.
- Never substitute a different fold's or altered parent's pools; all parent IDs, fitting-index hashes, pool hashes, and the gene-universe hash must verify.
- Never put ACT in either feature matrix.
- Never exceed 32 selected genes in either arm, 20 attempts, 21,600 cumulative seconds, or 3,600 seconds for one run.
- Never nominate a result that fails any gate or does not strictly beat frozen run 20.
